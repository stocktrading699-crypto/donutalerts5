DonutAlerts - Fabric mod for Minecraft 1.21.5

Menus (keys changeable in Options > Controls > DonutAlerts):
  /donutalerts            main menu            (K)
  /donutalerts move       move / resize boxes  (J)
  /donutalerts auction    auction menu         (L)   also /bidding
  /donutalerts queue      gamble queue menu    (key unbound by default)
  /donutalerts next       finish current person in the queue (key unbound by default)
  /donutalerts clear      empty the queue
  /bidding stop           stop the auction

BUILD: upload the "src" folder to your GitHub repo (the .github build file stays the same),
wait for the green check in Actions, download DonutAlerts-jar, put the .jar in Lunar's Fabric mods folder.
